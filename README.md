# PACT Evidence

**Record Today. Prove Tomorrow.**

PACT is a digital platform designed to help users create secure, timestamped records of important instructions, actions, outcomes, and supporting evidence. 

## 🚀 Features
- **Secure Authentication:** Easy and secure login using Google Sign-In (with Facebook and Phone/OTP coming soon).
- **Timestamped Records:** Generates reliable server-recorded timestamps and unique digital fingerprints for every submission.
- **Evidence Management:** Safely store screenshots, documents, and relevant files linked to your records.
- **Verification System:** Easily verify and reference past records using unique PACT IDs.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend & Database:** Firebase Authentication & Firestore
- **Hosting:** Vercel

## 📌 How It Works
1. **Submit Information:** Describe what happened, who gave the instruction, and who was involved.
2. **Add Evidence:** Attach relevant screenshots, documents, or files.
3. **Get PACT Record:** Receive a unique PACT ID and a verifiable timestamped digital record.
